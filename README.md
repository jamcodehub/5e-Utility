## Local Development

```bash
# Terminal 1 — backend
cd server
npm install
cp .env.example .env        # fill in MONGO_URI + JWT_SECRET
npm run dev                 # :4000

# Terminal 2 — frontend
cd client
npm install
npm run dev                 # :5173 (proxies /api → :4000)
```

## Deploying

### Backend → Render (free)
1. Push repo to GitHub
2. New Web Service on render.com → connect repo
3. Root dir: `server` | Build: `npm install` | Start: `npm start`
4. Set env vars: `MONGO_URI`, `CLIENT_URL` (your Netlify URL)
5. `JWT_SECRET` is auto-generated by render.yaml

### Frontend → Netlify
1. New site on netlify.com → connect same GitHub repo
2. Build settings are auto-detected from `netlify.toml`
3. Set env var: `VITE_API_URL` = your Render service URL (e.g. `https://lore-ledger-api.onrender.com`)
4. Deploy — done

### MongoDB
Use MongoDB Atlas (free tier):
- Create cluster → get connection string
- Paste into Render env var `MONGO_URI`
